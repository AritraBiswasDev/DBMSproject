📐 Mathematical Architecture & In-Database Novelty
1. Haversine Great-Circle Trigonometry

To compute instantaneous physical distance between consecutive ATM card swipes, the database uses spherical trigonometry:

d = 2R × arcsin(√(sin²(Δφ/2) + cos(φ&sub1;)cos(φ&sub2;)sin²(Δλ/2)))
Velocity (v) = Δd (km) / Δt (hours)

If v > 500 km/h, physical human travel is impossible without supersonic transport, establishing unambiguous fraud evidence.

2. SQL Window Function Temporal Partitioning

The database performs stateful temporal analysis without slow multi-table joins using SQL window functions:

LAG(atm_id, 1) OVER (PARTITION BY card_id ORDER BY transaction_date)
LAG(transaction_date, 1) OVER (PARTITION BY card_id ORDER BY transaction_date)

When flagged, the transaction engine triggers an automated ACID rollback, writes to fraud_alerts, and sets cards.status = 'BLOCKED'.
